# LuckyPeaches

Minecraft 幸运蟠桃插件 — 食用蟠桃可永久提升最大生命值。

## 功能

- **生命值提升**：使用蟠桃道具永久增加玩家最大生命值
- **可配置上限**：设置玩家最大生命值上限
- **PlaceholderAPI 集成**：提供占位符显示生命值信息
- **API 接口**：供其他插件调用查询和修改生命值数据

## 命令

| 命令 | 说明 | 权限 |
|------|------|------|
| `/lp` | 管理员主指令 | `luckypeach.admin` |

## 依赖
