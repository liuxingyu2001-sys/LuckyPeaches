# Plan: LuckyPeaches Proxy Plugin (Velocity)

## 目标

创建 Velocity 代理端插件，实现群组服统一管理：
- 配置分发与实时同步
- 全局蟠桃活动管理
- 跨服排行榜

## 数据库表设计

### 1. `lp_config` (已有)
```sql
CREATE TABLE lp_config (
  id INT PRIMARY KEY DEFAULT 1,
  config_data LONGTEXT,
  server_name VARCHAR(64),
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

### 2. `lp_events` (新增)
```sql
CREATE TABLE lp_events (
  id INT AUTO_INCREMENT PRIMARY KEY,
  event_type VARCHAR(32),        -- 'double_chance', 'extra_bonus', 'exp_boost'
  event_name VARCHAR(64),        -- 活动名称
  multiplier DOUBLE DEFAULT 1.0, -- 倍率
  extra_bonus DOUBLE DEFAULT 0.0, -- 额外加成
  start_time TIMESTAMP,
  end_time TIMESTAMP,
  is_active BOOLEAN DEFAULT true,
  created_by VARCHAR(64),        -- 创建者
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 3. `lp_config_sync` (新增 - 配置同步标记)
```sql
CREATE TABLE lp_config_sync (
  id INT PRIMARY KEY DEFAULT 1,
  config_hash VARCHAR(64),       -- 配置哈希，用于检测变更
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

## 功能设计

### 1. 配置分发

**流程：**
1. Velocity 插件启动时读取本地 `config.yml`
2. 写入 MySQL `lp_config` 表
3. 后端服务器启动时从 MySQL 读取配置

**配置内容：**
```yaml
# Velocity 端配置
database:
  host: localhost
  port: 3306
  database: luckypeaches
  username: root
  password: ""
  table_prefix: "lp_"

# 活动配置
events:
  double_chance:
    enabled: true
    multiplier: 2.0
  extra_bonus:
    enabled: true
    bonus: 1.0

# 排行榜配置
leaderboard:
  update_interval: 300  # 秒
  display_count: 10
```

### 2. 实时配置同步

**方案：**
- Velocity 插件检测配置变更
- 更新 MySQL `lp_config_sync` 表的 `config_hash`
- 后端服务器定期检查 `config_hash`（每 30 秒）
- 哈希变更时重新加载配置

**命令：**
```
/lp-proxy reload  -- 重新加载配置并同步到 MySQL
```

### 3. 全局蟠桃活动

**活动类型：**
- `double_chance` - 双倍蟠桃概率
- `extra_bonus` - 额外生命值加成
- `exp_boost` - 经验加成（如果需要）

**命令：**
```
/lp-proxy event start <类型> <倍率> <持续时间>  -- 开始活动
/lp-proxy event stop <ID>                       -- 结束活动
/lp-proxy event list                            -- 查看活动列表
/lp-proxy event status                          -- 查看当前活动
```

**后端服务器逻辑：**
- 吃蟠桃时检查 `lp_events` 表
- 如果有活跃活动，应用倍率/加成
- 活动结束后自动恢复

### 4. 跨服排行榜

**数据来源：**
- 后端服务器已有 `lp_player_peach_health` 表
- 所有服务器共享同一数据库

**命令：**
```
/lp-proxy top [数量]  -- 查看跨服排行榜
/lp-proxy rank <玩家> -- 查看玩家排名
```

**显示：**
- 使用 ActionBar 或 BossBar 显示排行榜
- 定期更新（可配置间隔）

## 后端服务器修改 (LuckyPeaches)

### 1. 活动检查

在 `PeachListener.onInteract()` 中添加：
```java
// 检查活动倍率
double chanceMultiplier = 1.0;
double extraBonus = 0.0;
if (databaseManager.isSyncConfig()) {
    EventData event = databaseManager.getActiveEvent("double_chance");
    if (event != null) {
        chanceMultiplier = event.getMultiplier();
    }
    event = databaseManager.getActiveEvent("extra_bonus");
    if (event != null) {
        extraBonus = event.getExtraBonus();
    }
}

// 应用活动倍率
double effectiveChance = config.chance * chanceMultiplier;
if (random.nextDouble() <= effectiveChance) {
    double bonus = config.healthBonus + extraBonus;
    // ...
}
```

### 2. 配置同步检查

定期检查 `lp_config_sync` 表的哈希值，如果变更则重新加载配置。
