# Plan: 添加 `/lp db` 数据库切换指令

## 目标

添加 `/lp db <type>` 指令，管理员可以在游戏内一键切换 SQLite ↔ MySQL，**默认自动迁移数据**，**支持热切换不踢人**。

## 指令设计

```
/lp db status       — 查看当前数据库类型
/lp db mysql        — 切换到 MySQL 并自动迁移数据
/lp db sqlite       — 切换到 SQLite 并自动迁移数据
```

## 需要修改的文件（共 4 个）

### 1. `DatabaseManager.java` — 新增迁移+热切换方法

新增字段：
- `sqliteFile`: 持有 `data.db` 的 File 引用

新增方法：
- `switchDatabase(String newType)`: 核心切换逻辑
  1. 读取当前全部数据到内存（`List<Object[]>`）
  2. 关闭当前连接
  3. 修改 config `settings.database.type` 并 saveConfig
  4. 重新创建 DatabaseManager 实例并 initialize（建表）
  5. 批量写入数据到新数据库
  6. 返回迁移记录数
- `readAllData()` / `writeAllData(List<Object[]> data)`: 数据迁移辅助方法
- `isUseMysql()` getter: 供外部查询当前类型

热切换关键：切换后 `LuckyPeaches` 中的 `databaseManager` 引用指向新实例，在线玩家的 modifier 不受影响（modifier 在内存中，切换数据库后重新加载数据即可）。

### 2. `LuckyPeaches.java` — 新增 `switchDatabase(String type)` 方法

```java
public void switchDatabase(String newType) {
    // 1. 保存所有在线玩家数据到旧数据库
    saveAllOnlinePlayers();
    // 2. 关闭旧数据库
    databaseManager.close();
    // 3. 调用 databaseManager.switchDatabase(newType)
    //    内部会修改 config、重新初始化
    // 4. 对所有在线玩家重新应用 modifier（从新数据库加载数据）
    reapplyModifiersForOnlinePlayers();
}
```

新增 `reapplyModifiersForOnlinePlayers()`:
- 遍历在线玩家
- 从新数据库加载 peach_bonus
- 重新应用 AttributeModifier

### 3. `PeachCommand.java` — 新增 `db` 子命令

switch 中添加 `case "db"`，调用 `handleDatabase(sender, args)`。

逻辑：
- `args[0] == "db"` 且 `args.length == 1` → 显示帮助
- `args[1] == "status"` → 显示当前类型
- `args[1] == "mysql"` 或 `"sqlite"` → 异步执行切换：
  1. 发送"正在切换..."消息
  2. `runTaskAsynchronously` 执行迁移
  3. 成功后 `runTask` 重新应用 modifier 并发送结果

Tab 补全：
- `/lp db ` → `status`, `mysql`, `sqlite`

### 4. `messages.yml` — 新增 7 条消息

```yaml

db_switching: "&e正在切换数据库类型为 &a%type%&e 并迁移数据，请稍候..."

  - "&e/lp db status &7- 查看当前数据库类型"
```

同时在 help 消息中添加一行：
```yaml
  - "&e/lp db <mysql|sqlite|status> &7- 切换数据库类型"
```

## 热切换流程（不踢人）

```
玩家在线 → /lp db mysql
  ↓
保存所有在线玩家数据到 SQLite
  ↓
关闭 SQLite 连接
  ↓
修改 config → 初始化 MySQL 连接 → 建表
  ↓
读取 SQLite 全部数据 → 写入 MySQL
  ↓
关闭旧 SQLite 连接
  ↓
对每个在线玩家：从 MySQL 重新加载数据 → 重新应用 modifier
  ↓
玩家无感知，血量不变
```

## 验证方式

1. `mvn clean package -q` 编译
2. 测试服务器中：
   - `/lp db status` → sqlite
   - `/lp db mysql` → 显示迁移中... → 迁移完成
   - `/lp db status` → mysql
   - 确认在线玩家血量不变
   - `/lp db sqlite` → 切换回来
   - 确认数据一致
