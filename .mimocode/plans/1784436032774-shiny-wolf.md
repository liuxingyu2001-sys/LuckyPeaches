# 添加 MySQL 数据库支持

## 目标

在保留 SQLite（默认）的基础上，增加 MySQL 数据库支持，适用于多服务器/bungeecord 环境。

## 需要修改的文件

| 文件 | 改动 |
|------|------|
| `pom.xml` | 添加 MySQL Connector + HikariCP 依赖 |
| `config.yml` | 新增 `database` 配置节（type/mysql/sqlite） |
| `DatabaseManager.java` | 重构为支持双数据库，处理 SQL 方言差异 |
| `BackupManager.java` | MySQL 备份逻辑（mysqldump 或跳过） |
| `README.md` | 更新依赖和配置说明 |

## 实现方案

### 1. pom.xml — 新增依赖

```xml
<!-- MySQL Connector (runtime) -->
<dependency>
    <groupId>mysql</groupId>
    <artifactId>mysql-connector-java</artifactId>
    <version>8.0.33</version>
    <scope>runtime</scope>
</dependency>

<!-- HikariCP 连接池 -->
<dependency>
    <groupId>com.zaxxer</groupId>
    <artifactId>HikariCP</artifactId>
    <version>5.1.0</version>
</dependency>
```

### 2. config.yml — 新增 database 节

在 `settings` 下新增：

```yaml
settings:
  database:
    # 数据库类型: sqlite 或 mysql
    type: sqlite
    # MySQL 配置（仅 type: mysql 时生效）
    mysql:
      host: localhost
      port: 3306
      database: luckypeaches
      username: root
      password: ""
      table_prefix: ""
      max_connections: 10
```

### 3. DatabaseManager.java — 核心重构

**策略**：不使用继承，用 `boolean useMysql` 标志 + SQL 方言处理。

关键差异处理：

| 操作 | SQLite | MySQL |
|------|--------|-------|
| Upsert | `INSERT OR REPLACE INTO` | `INSERT INTO ... ON DUPLICATE KEY UPDATE` |
| 建表 | `TEXT PRIMARY KEY` | `VARCHAR(36) PRIMARY KEY` |
| 列检查 | `PRAGMA table_info(...)` | `SHOW COLUMNS FROM ...` |
| 备份 | `VACUUM INTO` | `mysqldump` 或跳过 |
| 连接 | 单连接 | HikariCP 连接池 |

**连接池**：MySQL 使用 HikariCP，SQLite 保持单连接（SQLite 不支持并发写入）。

**公共方法签名不变**，内部根据 `useMysql` 选择 SQL。

### 4. BackupManager.java

- SQLite：保持现有 `VACUUM INTO` 逻辑
- MySQL：备份功能禁用（提示使用 mysqldump），或可选执行 `mysqldump` 命令

### 5. SQL 方言适配

```java
// Upsert
private String upsertSQL() {
    if (useMysql) {
        return "INSERT INTO player_peach_health (uuid, username, peach_bonus, current_health, last_updated) " +
               "VALUES (?, ?, ?, ?, NOW()) ON DUPLICATE KEY UPDATE " +
               "username=VALUES(username), peach_bonus=VALUES(peach_bonus), " +
               "current_health=VALUES(current_health), last_updated=NOW()";
    }
    return "INSERT OR REPLACE INTO player_peach_health " +
           "(uuid, username, peach_bonus, current_health, last_updated) " +
           "VALUES (?, ?, ?, ?, CURRENT_TIMESTAMP)";
}

// 建表
private String createTableSQL() {
    if (useMysql) {
        return "CREATE TABLE IF NOT EXISTS player_peach_health (" +
               "uuid VARCHAR(36) PRIMARY KEY, " +
               "username VARCHAR(16), " +
               "peach_bonus DOUBLE, " +
               "current_health DOUBLE, " +
               "last_updated TIMESTAMP DEFAULT CURRENT_TIMESTAMP" +
               ") ENGINE=InnoDB DEFAULT CHARSET=utf8mb4";
    }
    return "CREATE TABLE IF NOT EXISTS player_peach_health (" +
           "uuid TEXT PRIMARY KEY, " +
           "username TEXT, " +
           "peach_bonus REAL, " +
           "current_health REAL, " +
           "last_updated TIMESTAMP DEFAULT CURRENT_TIMESTAMP" +
           ")";
}
```

## 实现顺序

1. `pom.xml` — 添加依赖
2. `config.yml` — 添加 database 配置节
3. `DatabaseManager.java` — 重构（最大改动）
4. `BackupManager.java` — MySQL 备份处理
5. `README.md` — 更新文档
6. 编译验证

## 验证

- `mvn clean package` 编译通过
- 默认配置（SQLite）行为不变
- 配置 `type: mysql` 时连接 MySQL 并建表
